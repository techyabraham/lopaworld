# Lopaworld

Mobile-first Nigerian fashion storefront across seven labels, using one catalogue, bag and checkout.

## Start locally

See [the local runbook](docs/RUNBOOK.md) for prerequisites and the first-run steps. In short: copy `.env.example` to `.env`, start Docker dependencies with `pnpm infra:up`, install with `pnpm install`, then run `pnpm dev`.

The current workspace is the Phase 0 foundation. Product, label and delivery content is intentionally not invented; see [open owner inputs](docs/OPEN_ITEMS.md).
